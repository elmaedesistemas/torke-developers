## Como fica no código

Uma sessão, um `arm()` e eventos. O cronômetro começa sozinho quando o carro larga.

<Tabs syncKey="platform">
<TabItem label="Swift">

```swift
import TorkeKit
import TorkeKitSensors

let session = RunSession()
session.start(with: PhoneSensorProvider())
session.arm()

for await event in session.events() {
    if case .finished(let result) = event {
        print("1/4 de milha: \(result.quarterMile!) s a \(result.quarterMileKmh!) km/h")
    }
}
```

</TabItem>
<TabItem label="Kotlin">

```kotlin
import today.torke.kit.session.*
import today.torke.kit.sensors.PhoneSensorProvider

val session = RunSession()
session.start(PhoneSensorProvider(context), lifecycleScope)
session.arm()

session.events.collect { event ->
    if (event is RunEvent.Finished) {
        println("1/4 de milha: ${event.result.quarterMile} s a ${event.result.quarterMileKmh} km/h")
    }
}
```

</TabItem>

## O que resolve

<CardGrid>
	<Card title="Tempos de pista" icon="rocket">
		60 pés, 1/8 e 1/4 de milha com velocidade final, 0 a 100 km/h, 0 a 60 mph, 1000 pés e meia milha. Desconta o pé
		de rollout, como o cronômetro da pista.
	</Card>
	<Card title="Largada automática" icon="approve-check">
		Detecta quando o carro está parado, arma a arrancada e começa a medir no instante da largada. Sem botões com o
		carro na linha.
	</Card>
	<Card title="Clima, potência e qualidade" icon="star">
		Correção SAE J1349, altitude de densidade, cavalos estimados e uma nota por arrancada: boa, regular ou ruim, com
		o motivo.
	</Card>
	<Card title="Geometria de suspensão" icon="puzzle">
		4-link, ladder bar e torque arm: centro instantâneo, anti-squat e quais furos testar. Fórmulas de livro, sem
		valores de ninguém.
	</Card>
</CardGrid>
