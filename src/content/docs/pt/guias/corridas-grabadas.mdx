Cada arrancada pode ser salva com **todas as amostras brutas** (acelerômetro e GPS) mais o resultado. Com isso você pode recalcular os tempos quando quiser: em outro celular, no seu servidor ou em um teste automático.

## Salvar

Quando chegar `finished`, peça a gravação à sessão e converta em JSON:

<Tabs syncKey="platform">
<TabItem label="Swift">

```swift
let run = session.recording(device: "iPhone16,1", app: "MeuApp 1.0")
let data = try run.encoded()            // o JSON torke.run
try data.write(to: url)
```

</TabItem>
<TabItem label="Kotlin">

```kotlin
val run = session.recording(device = Build.MODEL, app = "MeuApp 1.0")
val json = run.encode()                 // o JSON torke.run
file.writeText(json)
```

</TabItem>
</Tabs>

Uma arrancada de quarto de milha pesa uns 200 KB. Use a extensão `.torkerun.json`.

## Analisar de novo

<Tabs syncKey="platform">
<TabItem label="Swift">

```swift
let run = try TorkeRun.decode(data)
let result = run.analyze()              // os tempos de novo
let start = run.startLocation           // onde largou
```

</TabItem>
<TabItem label="Kotlin">

```kotlin
val run = TorkeRun.decode(json)
val result = run.analyze()              // os tempos de novo
val start = run.startLocation           // onde largou
```

</TabItem>
</Tabs>

<Aside type="tip" title="No seu servidor">
O módulo `torke-kit` do Android não tem código Android: adicione-o a um servidor em Kotlin ou Java e recalcule os tempos de cada arrancada enviada. Assim o ranking não depende do número que o celular mandou.
</Aside>

## Reproduzir

`RecordedRunProvider` passa uma arrancada gravada para uma sessão como se fossem os sensores. Serve para testes, demos e para investigar um erro relatado.

<Tabs syncKey="platform">
<TabItem label="Swift">

```swift
let session = RunSession()
session.arm()
await session.run(with: RecordedRunProvider(run))                 // o mais rápido possível
session.start(with: RecordedRunProvider(run, speed: 1))           // em tempo real, para uma demo
```

</TabItem>
<TabItem label="Kotlin">

```kotlin
val session = RunSession()
session.arm()
session.run(RecordedRunProvider(run))                             // o mais rápido possível
session.start(RecordedRunProvider(run, speed = 1.0), scope)       // em tempo real, para uma demo
```

</TabItem>
</Tabs>

## Testes automáticos

A arrancada simulada (`RecordedRunProvider.demo()`) sempre dá os mesmos números. Use-a para fixar o comportamento do seu app:

<Tabs syncKey="platform">
<TabItem label="Swift">

```swift
func testDemoRun() async throws {
    let session = RunSession()
    session.arm()
    await session.run(with: RecordedRunProvider.demo())
    let r = try XCTUnwrap(session.snapshot.result)
    XCTAssertEqual(r.quarterMile!, 12.826, accuracy: 0.001)
}
```

</TabItem>
<TabItem label="Kotlin">

```kotlin
@Test fun demoRun() = runTest {
    val session = RunSession()
    session.arm()
    session.run(RecordedRunProvider.demo())
    val r = session.snapshot.value.result!!
    assertEquals(12.826, r.quarterMile!!, 0.001)
}
```

</TabItem>
</Tabs>
