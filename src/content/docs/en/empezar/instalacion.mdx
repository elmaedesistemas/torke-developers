## Add the package

<Tabs syncKey="platform">
<TabItem label="Swift">

In Xcode: **File → Add Package Dependencies…** and paste the repository URL. Or in your `Package.swift`:

```swift title="Package.swift"
dependencies: [
    .package(url: "https://github.com/elmaedesistemas/torke-kit-ios", from: "0.3.0")
],
targets: [
    .target(name: "MyApp", dependencies: [
        .product(name: "TorkeKit", package: "torke-kit-ios"),
        .product(name: "TorkeKitSensors", package: "torke-kit-ios"),
    ])
]
```

| Product | What it has | Depends on |
| --- | --- | --- |
| `TorkeKit` | The engine, `RunSession`, the `torke.run` format, `RecordedRunProvider`, `DemoRun` | Foundation only (iOS 17, macOS 14) |
| `TorkeKitSensors` | `PhoneSensorProvider` (CoreMotion + CoreLocation), `PhoneBarometer` | iOS |

</TabItem>
<TabItem label="Kotlin">

TorkeKit is published on JitPack. Add the repository and the dependency:

```kotlin title="settings.gradle.kts"
dependencyResolutionManagement {
    repositories {
        google()
        mavenCentral()
        maven("https://jitpack.io")
    }
}
```

```kotlin title="app/build.gradle.kts"
dependencies {
    implementation("com.github.elmaedesistemas.torke-kit-android:torke-kit-sensors:0.3.0")
    // Only the core, without Android (a server, tests):
    // implementation("com.github.elmaedesistemas.torke-kit-android:torke-kit:0.3.0")
}
```

| Module | What it has | Depends on |
| --- | --- | --- |
| `torke-kit` | The engine, `RunSession`, the `torke.run` format, `RecordedRunProvider`, `DemoRun` | Kotlin (JVM), coroutines, kotlinx.serialization |
| `torke-kit-sensors` | `PhoneSensorProvider` (SensorManager + LocationManager), `PhoneBarometer` | Android, `minSdk 26` |
| `torke-validate` | The validation command | Java 17 |

</TabItem>
</Tabs>

## Ask for permissions

<Tabs syncKey="platform">
<TabItem label="Swift">

<Steps>

1. **Explain what you use the sensors for** in `Info.plist`:

   ```xml title="Info.plist"
   <key>NSLocationWhenInUseUsageDescription</key>
   <string>We use the GPS to measure the speed and distance of your runs.</string>
   <key>NSMotionUsageDescription</key>
   <string>We use the accelerometer to detect the launch and time the 60 feet.</string>
   ```

2. **Ask for permission before arming the run:**

   ```swift
   let phone = PhoneSensorProvider()
   await phone.requestPermission()
   ```

3. **Keep the screen on** while recording:

   ```swift
   UIApplication.shared.isIdleTimerDisabled = true
   ```

</Steps>

</TabItem>
<TabItem label="Kotlin">

<Steps>

1. **Declare the permission** in `AndroidManifest.xml`:

   ```xml title="AndroidManifest.xml"
   <uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
   ```

2. **Ask for precise location before creating the provider:**

   ```kotlin
   val ask = rememberLauncherForActivityResult(ActivityResultContracts.RequestPermission()) { granted ->
       if (granted) phone = PhoneSensorProvider(context)
   }
   ask.launch(Manifest.permission.ACCESS_FINE_LOCATION)
   ```

3. **Keep the screen on** while recording:

   ```kotlin
   window.addFlags(WindowManager.LayoutParams.FLAG_KEEP_SCREEN_ON)
   ```

   To record with the screen off, collect inside a foreground service of type `location`.

</Steps>

</TabItem>
</Tabs>
