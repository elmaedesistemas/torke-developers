## What it looks like

A session, an `arm()` and events. The timer starts by itself when the car launches.

<Tabs syncKey="platform">
<TabItem label="Swift">

```swift
import TorkeKit
import TorkeKitSensors

let session = RunSession()
session.start(with: PhoneSensorProvider())
session.arm()

for await event in session.events() {
    if case .finished(let result) = event {
        print("1/4 mile: \(result.quarterMile!) s at \(result.quarterMileKmh!) km/h")
    }
}
```

</TabItem>
<TabItem label="Kotlin">

```kotlin
import today.torke.kit.session.*
import today.torke.kit.sensors.PhoneSensorProvider

val session = RunSession()
session.start(PhoneSensorProvider(context), lifecycleScope)
session.arm()

session.events.collect { event ->
    if (event is RunEvent.Finished) {
        println("1/4 mile: ${event.result.quarterMile} s at ${event.result.quarterMileKmh} km/h")
    }
}
```

</TabItem>

## What it does

<CardGrid>
	<Card title="Dragstrip times" icon="rocket">
		60 ft, 1/8 and 1/4 mile with trap speed, 0–100 km/h, 0–60 mph, 1000 ft and half mile. It discounts the
		one-foot rollout, like the track's timer.
	</Card>
	<Card title="Automatic start" icon="approve-check">
		Detects when the car stands still, arms the run and starts timing the instant it launches. No buttons with the
		car on the line.
	</Card>
	<Card title="Weather, power and quality" icon="star">
		SAE J1349 correction, density altitude, estimated horsepower and a grade for every run: good, fair or poor, with
		the reason.
	</Card>
	<Card title="Suspension geometry" icon="puzzle">
		4-link, ladder bar and torque arm: instant center, anti-squat and which holes to try. Textbook formulas, nobody's
		numbers.
	</Card>
</CardGrid>

## Who it's for

<CardGrid>
	<Card title="Timing apps" icon="laptop">

	<Card title="Tracks and organizers" icon="server">
