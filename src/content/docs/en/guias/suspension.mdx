On a rear-wheel-drive car, the suspension decides how weight transfers at the launch, and that shows straight up in the **60-foot time**. TorkeKit computes the side-view geometry with textbook formulas: where the **instant center** (IC) sits and how much **anti-squat** the car has.

## Lab

<SuspensionLab />

Both bars extend until they cross: that point is the **instant center**. The amber line runs from the rear tire's contact patch, through the IC, to the front axle. If it reaches exactly the height of the center of gravity (the dashed line), anti-squat is 100 %.

`antiSquat = (icHeight / icLength) / (cgHeight / wheelbase) × 100`

## Measuring your car

Every measurement is in a side view, with the car on the ground and the driver in:

- **`x`**: forward from the rear axle centerline.
- **`y`**: up from the ground.
- In **inches** or **centimeters**, never mixed (`LengthUnit`). `converted(to:)` changes everything at once.

| Point | What it is |
| --- | --- |
| `upperRear`, `upperFront` | Upper bar mounts on the axle and on the chassis. |
| `lowerRear`, `lowerFront` | Lower bar mounts on the axle and on the chassis. |
| `pivot` | Ladder bar: the front pivot point (it is the IC). |
| `armFront` | Torque arm: the arm's front mount. |
| `wheelbase`, `cgHeight` | Wheelbase and center-of-gravity height. |

## In code

<Tabs syncKey="platform">
<TabItem label="Swift">

```swift
let setup = SuspensionSetup.fourLink(
    wheelbase: 106, cgHeight: 21,
    upperRear: Point2(x: 4, y: 21), upperFront: Point2(x: 30, y: 18),
    lowerRear: Point2(x: 2, y: 9), lowerFront: Point2(x: 30, y: 11)
)

let g = setup.geometry()
g.icLength       // inches forward of the axle
g.icHeight       // inches above the ground
g.antiSquat      // %
g.bars           // angle and length of each bar
g.warnings       // .parallelLinks, .instantCenterBehindAxle…

// The other suspensions
SuspensionSetup.ladderBar(wheelbase: 106, cgHeight: 21, pivot: Point2(x: 48, y: 10))
SuspensionSetup.torqueArm(wheelbase: 106, cgHeight: 21, armFront: Point2(x: 40, y: 18),
                          lowerRear: Point2(x: 0, y: 10), lowerFront: Point2(x: 36, y: 11))
```

| Warning | What it means |
| --- | --- |
| `incomplete` | Points are missing for that kind of suspension. |
| `parallelLinks` | The bars are parallel: the IC is at infinity. |
| `instantCenterBehindAxle` | The IC is at or behind the axle: no anti-squat. |
| `instantCenterBelowGround` | The IC is below the ground. |

## Which holes to try

4-link brackets have several holes. With a **target window** (the ranges you want) and the available holes, TorkeKit tries every combination and sorts them from closest to farthest:

<Tabs syncKey="platform">
<TabItem label="Swift">

```swift
let target = TargetWindow(
    icLength: ValueRange(60, 75),
    icHeight: ValueRange(8, 12),
    antiSquat: ValueRange(80, 110)
)
let holes = FourLinkHoles(
    upperRear: [Point2(x: 4, y: 19), Point2(x: 4, y: 21), Point2(x: 4, y: 23)],
    upperFront: [Point2(x: 30, y: 18)],
    lowerRear: [Point2(x: 2, y: 8), Point2(x: 2, y: 9)],
    lowerFront: [Point2(x: 30, y: 11)]
)

for option in holes.ranked(base: setup, target: target).prefix(3) {
    print(option.holes, option.geometry.antiSquat!, option.score)
}
target.status(.antiSquat, of: setup.geometry())   // .inside, .near, .below or .above
```

</TabItem>
<TabItem label="Kotlin">

```kotlin
val target = TargetWindow(
    icLength = ValueRange(60.0, 75.0),
    icHeight = ValueRange(8.0, 12.0),
    antiSquat = ValueRange(80.0, 110.0),
)
val holes = FourLinkHoles(
    upperRear = listOf(Point2(4.0, 19.0), Point2(4.0, 21.0), Point2(4.0, 23.0)),
    upperFront = listOf(Point2(30.0, 18.0)),
    lowerRear = listOf(Point2(2.0, 8.0), Point2(2.0, 9.0)),
    lowerFront = listOf(Point2(30.0, 11.0)),
)

holes.ranked(setup, target).take(3).forEach { option ->
    println("${option.holes} ${option.geometry.antiSquat} ${option.score}")
}
target.status(TargetWindow.Metric.antiSquat, setup.geometry())   // inside, near, below or above
```

</TabItem>
</Tabs>

`holes` says which hole of each list to use (in the order `upperRear`, `upperFront`, `lowerRear`, `lowerFront`). A score of 0 means it falls inside every range.

<Aside type="caution" title="The target values are yours">
TorkeKit ships no recommended values from any manufacturer or driver. They depend on the car, the tires, the power and the track: set them yourself, or let your users set them.
</Aside>

## Comparing a change with the run

Save the suspension with each run (the `torke.run` format has a `suspension` field) and show what changed next to the 60-foot time:

<Tabs syncKey="platform">
<TabItem label="Swift">

```swift
let change = SetupChange(from: before, to: after)
change.antiSquat     // +12.5 (percentage points)
change.icLength      // -3.0 inches
change.moved         // ["upperRear": Point2(x: 0, y: 2)]
```

</TabItem>
<TabItem label="Kotlin">

```kotlin
val change = SetupChange.between(before, after)
change.antiSquat     // +12.5 (percentage points)
change.icLength      // -3.0 inches
change.moved         // {upperRear=Point2(x=0.0, y=2.0)}
```

</TabItem>
</Tabs>

That way the user sees, say, “you raised the upper hole 2 inches: anti-squat +12 %, 60 ft −0.04 s”.
