## Así se ve en código

Una sesión, un `arm()` y eventos. El cronómetro arranca solo cuando el carro sale.

<Tabs syncKey="platform">
<TabItem label="Swift">

```swift
import TorkeKit
import TorkeKitSensors

let session = RunSession()
session.start(with: PhoneSensorProvider())
session.arm()

for await event in session.events() {
    if case .finished(let result) = event {
        print("1/4 de milla: \(result.quarterMile!) s a \(result.quarterMileKmh!) km/h")
    }
}
```

</TabItem>
<TabItem label="Kotlin">

```kotlin
import today.torke.kit.session.*
import today.torke.kit.sensors.PhoneSensorProvider

val session = RunSession()
session.start(PhoneSensorProvider(context), lifecycleScope)
session.arm()

session.events.collect { event ->
    if (event is RunEvent.Finished) {
        println("1/4 de milla: ${event.result.quarterMile} s a ${event.result.quarterMileKmh} km/h")
    }
}
```

</TabItem>

## Qué resuelve

<CardGrid>
	<Card title="Tiempos de pista" icon="rocket">
		60 pies, 1/8 y 1/4 de milla con velocidad de trampa, 0 a 100 km/h, 0 a 60 mph, 1000 pies y media milla. Descuenta

		con el carro en la línea.
	</Card>
	<Card title="Clima, potencia y calidad" icon="star">

		el motivo.
	</Card>
	<Card title="Geometría de suspensión" icon="puzzle">

		valores de nadie.
	</Card>
</CardGrid>
